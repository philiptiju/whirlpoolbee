sync Sync & AI-Assisted PR Stats

Sync pulls every project and Git repository directly from the Azure DevOps API — no manual repo setup needed. Sessions are linked to PRs by matching the session's logged-in user against commit authors within a time window. AI % is the share of a PR's commits made while that author had an active Claude Code session running — not a line-of-code diff (Azure DevOps doesn't expose that cheaply at full-org scale).
